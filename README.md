# EdgeJot

一个面向 Windows 的轻量便签工具。

## 技术栈

- Rust：应用逻辑和数据管理
- `windows` crate：原生 Win32 窗口、托盘和快捷键
- SQLite：便签持久化

## 当前状态

项目已完成基础初始化，并包含：

- SQLite 数据库创建、WAL 模式和首版便签表结构
- 右侧屏幕边缘悬浮胶囊，随便签数量从 48px 增长至 94px
- 胶囊圆点保持固定尺寸和间距，最多展示 7 个颜色状态
- 鼠标悬停展开透明便签卡组，颜色与胶囊圆点对应
- 列表以胶囊为中心向左滑出并淡入，收起时平滑回滑；展开后覆盖胶囊位置
- 卡片与文字使用透明窗口专用抗锯齿绘制
- 标签悬停向左突出 9px，使用 150ms OutCubic 动画
- 标签与文字预渲染缓存，动画帧使用内存合成和亚像素插值
- 字体对齐小顾便签：Microsoft YaHei UI / Segoe UI
- 当前字阶：列表标识 12 DIP、卡片标签 14 DIP 中等字重，列表按钮符号使用 Segoe UI
- 文字使用 DirectWrite Natural Symmetric 灰阶抗锯齿，适配透明分层窗口
- 底部“+”按钮创建 SQLite 便签
- 点击便签卡片可在列表左侧打开编辑器，支持标题、正文、实时字数和本地自动保存
- 右键便签卡片可置顶、取消置顶或删除；删除前会再次确认，置顶状态持久化到 SQLite
- 切换卡片时编辑器左侧色条同步对应便签颜色；编辑器与列表保持组合展示，点击“−”只收起编辑器并保留列表
- 编辑器采用米白圆角面板、左侧“速记胶囊”栏，并提供最小化、关闭与拖动操作；点击工作区外部会自动保存并整体收起
- 编辑器侧栏与底部文字使用 14 DIP 字号、更高对比度和灰阶抗锯齿；最小化、关闭按钮使用按物理像素对齐的抗锯齿矢量线条
- 标题和正文始终由同一个原生输入控件显示，使用像素对齐的 ClearType 字体；正文为 16 DIP，聚焦、失焦不再切换文字渲染方式或重置滚动位置，空内容显示可点击的提示文字
- 编辑器复用 Direct2D / DirectWrite 绘图资源和离屏缓冲，整帧绘制后一次呈现，避免背景重绘覆盖正在输入的控件
- Windows 11 编辑器采用 DWM 原生圆角、细边框和阴影，替代硬裁剪圆角；Windows 10 保留兼容的窗口区域裁剪
- 编辑器跨屏切换 DPI 时同步更新控件位置、字体和圆角区域，按目标屏幕的原生分辨率重绘
- 列表采用 48px 行距和 65px 卡片高度的重叠布局，固定视口最多露出 6 张，超过后可用鼠标滚轮连续滑动
- 新的滚轮输入会直接改变当前滚动目标并保留运动速度；列表静态图层和卡片精灵复用预渲染缓存，动画帧只进行内存合成
- 输入时仅刷新底部状态区域；自动保存仅在列表顺序改变时重置动画，标题修改复用卡片背景几何缓存，避免反复计算圆角抗锯齿
- 多显示器边缘吸附
- 沿屏幕边缘上下拖动
- 每显示器 DPI 感知与抗锯齿透明圆角

运行后将鼠标移到胶囊上可展开便签列表，按住胶囊左键可以上下拖动，右键胶囊可退出；右键列表中的便签卡片可管理该便签。

默认数据文件：`%LOCALAPPDATA%\Noty\noty.db`

首次运行时，Noty 会为当前 Windows 用户在 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 注册自启；此后登录该电脑时自动启动。启动项指向当前运行的程序文件，应用移动到新位置后再次运行会更新路径，无需管理员权限。Windows「启动应用」设置可禁用该启动项；请将程序放在长期保留的位置后再使用。
