# Noty

一个面向 Windows 的轻量便签工具。

## 技术栈

- Rust：应用逻辑和数据管理
- `windows` crate：原生 Win32 窗口、托盘和快捷键
- SQLite：便签持久化

## 当前状态

项目已完成基础初始化，并包含：

- SQLite 数据库创建、WAL 模式和首版便签表结构
- 右侧屏幕边缘悬浮胶囊，随便签数量从 48px 增长至 94px
- 胶囊圆点保持固定尺寸和间距，最多展示 7 个颜色状态
- 鼠标悬停展开透明便签卡组，颜色与胶囊圆点对应
- 列表以胶囊为中心向左滑出并淡入，收起时平滑回滑；展开后覆盖胶囊位置
- 卡片与文字使用透明窗口专用抗锯齿绘制
- 标签悬停向左突出 9px，使用 150ms OutCubic 动画
- 标签与文字预渲染缓存，动画帧使用内存合成和亚像素插值
- 字体对齐小顾便签：Microsoft YaHei UI / Segoe UI
- 当前字阶：侧栏标识 10px、卡片标签 12px 中等字重，按钮符号使用 Segoe UI
- 文字使用 DirectWrite Natural Symmetric 灰阶抗锯齿，适配透明分层窗口
- 底部“+”按钮创建 SQLite 便签
- 点击便签卡片可在列表左侧打开编辑器，支持标题、正文、实时字数和本地自动保存
- 切换卡片时编辑器左侧色条同步对应便签颜色；点击工作区外部会自动保存并收起
- 编辑器采用米白圆角面板、左侧“速记胶囊”栏，并提供最小化、关闭与拖动操作
- 列表固定最多展示 6 张，超过后可用鼠标滚轮逐张浏览；卡组会沿滚动方向滑入，新进入的卡片短暂突出后归位
- 重复标题和颜色的卡片复用预渲染缓存，避免滚动时反复生成文字和圆角图层
- 多显示器边缘吸附
- 沿屏幕边缘上下拖动
- 每显示器 DPI 感知与抗锯齿透明圆角

运行后将鼠标移到胶囊上可展开便签列表，按住胶囊左键可以上下拖动，右键单击退出。

默认数据文件：`%LOCALAPPDATA%\Noty\noty.db`
